Projects

SemaKazi

Personal project · Sole developer

A skills-verification and reputation platform for Kenya's informal-sector workers (fundis), who usually have no way to prove their competence beyond word of mouth.

Problem
Clients can't tell a skilled fundi from someone posing as one, so good workers stay limited to their existing network.
Approach
Public profiles built from three trust signals: photo proof of completed jobs, client ratings, and peer-endorsed skill badges. Search by trade and location.
Key decision
Scoped a deliberate MVP in a written PRD and left payments, escrow and chat out, so the trust model could be built and tested first.
Status
Registration, login, search, profiles with reviews, and the fundi dashboard work end to end. Production deployment is in progress.

Node.js · Express · SQLite · JWT + bcrypt · HTML/CSS/JS

Duka POS

Personal project · Sole developer

Point-of-sale and inventory software for small Kenyan shops, designed to run on a single machine with no cloud dependency.

Problem
Small shops need sales, stock and staff control without paying for hosted POS systems or reliable internet.
Approach
Owner and cashier roles with bcrypt-hashed PINs, camera barcode scanning, printable receipts, low-stock alerts, a 7-day CSV report, an English/Swahili toggle, and multi-shop support.
Key decision
Stock deduction runs atomically at checkout so two cashiers can't oversell the last item, and every row is scoped by shop so one owner can run several shops.
Verification
A 20-test suite runs against an in-memory SQLite database.

Node.js · Express · EJS · SQLite
